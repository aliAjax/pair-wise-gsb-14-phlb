# 油品价格维护 · 会员折扣台账

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

在“油品价格维护”基础上扩展出的**会员折扣台账**：每条策略绑定油品、会员等级、
折扣率、生效区间与审批编号，按版本链管理，数据保存在浏览器 localStorage 中。

## 业务规则

1. 每条策略包含：油品、会员等级、折扣率、生效区间（开始~结束，可长期）、审批编号、原因、操作员。
2. **同一油品 + 同一会员等级的有效策略区间不得重叠**（R5）。
3. 优惠后价格（挂牌价 × 折扣率）**低于成本价时必须填写审批编号**，否则整单拒绝，草稿保留（R4）。
4. 撤回：**仅未生效的最新版本可撤回**，撤回后上一版区间恢复为原始区间（R7）。
5. 已生效价格不能撤回/覆盖，**只能新建带原因的版本**（R6）；旧版本与旧价保留在版本链中可查。
6. 刷新后策略状态、当前会员价、版本链来自同一份数据，始终一致；冲突清单列出
   **油品、会员等级、冲突区间、触发规则**（规则编号 + 名称 + 说明）。

状态模型：`upcoming 未生效 / active 生效中 / expired 已过期 / withdrawn 已撤回`，按基准日（今天）重算。

## 分层结构（规则、存储、页面分开）

```
src/discount/
├── types.ts       # 领域模型（油品/等级/策略/版本链/草稿/冲突）
├── time.ts        # 纯日期工具（区间重叠、生效判定）
├── catalog.ts     # 油品（成本价/挂牌价）、会员等级、规则目录 R1~R7
├── rules.ts       # 规则层：校验、提交落版本、撤回、状态刷新（纯函数，无 Vue/存储依赖）
├── selectors.ts   # 派生查询：当前价看板、版本链摘要（纯函数）
├── seed-data.ts   # 示例台账种子数据
├── storage.ts     # 存储层：localStorage 读写、损坏回退
├── store.ts       # Pinia：编排规则层与存储层（页面唯一数据入口）
├── ui.ts          # 页面展示辅助（状态文案、折扣/价格格式）
└── components/    # 页面层
    ├── MemberDiscountPage.vue  # 页面组合：指标 / 表单 / 冲突 / 看板 / 台账
    ├── DiscountForm.vue        # 策略表单（新建、调价草稿、实时低价预警）
    ├── ConflictList.vue        # 冲突清单（油品/等级/区间/触发规则）
    ├── CurrentPriceBoard.vue   # 当前会员价看板（油品 × 等级）
    └── VersionChain.vue        # 版本链台账（展开版本、撤回、发起调价）
```

规则全部集中在 `catalog.ts` 的 `RULES` 目录与 `rules.ts` 中：R1 必填、R2 折扣率范围、
R3 区间合法性、R4 低价强制审批、R5 区间不重叠、R6 调价必填原因、R7 撤回限制；
存储层与页面层不内联任何规则。
