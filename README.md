# 会员折扣台账（油品价格维护扩展）

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`
- 规则测试：`npm run test:rules && npm run test:store`

数据保存在浏览器 localStorage（折扣版本 / 油品价格 / 被拒草稿三个键），刷新后策略、当前价与版本链保持一致。

## 业务规则

1. 每条策略选择：油品、会员等级、折扣率、生效区间、审批编号。
2. **区间不重叠**：同一油品 + 同一会员等级在同一天最多只有一条有效版本。
3. **低于成本价必须审批**：优惠后价（挂牌价 × 折扣率）低于成本价时必须填写审批编号，否则整单拒绝并保留草稿。
4. **撤回只允许未生效项**：撤回后按快照恢复上一版区间；已生效 / 已失效项只能“新建带原因版本”。
5. **旧价可查**：版本只增不改，修订时旧版区间截至新版开始日前一天，折扣值与建版挂牌价快照永久保留在版本链。

冲突列表统一给出：触发规则、油品、会员等级、冲突区间与说明。

## 分层结构（规则 / 存储 / 页面分开）

```
src/ledger/
├── rules.ts                  # 规则层：类型、规则台账、区间/价格/状态推导、整单校验（纯函数）
├── store.ts                  # 存储层：Pinia + localStorage、版本链编排（截断/撤回恢复/草稿保留）
├── LedgerPage.vue            # 页面装配
└── components/
    ├── StrategyForm.vue      # 策略录入、低价预览、整单拒绝冲突清单、规则台账
    ├── StrategyLedger.vue    # 策略台账（筛选、新建版本、撤回）
    ├── CurrentPrices.vue     # 当前价矩阵（实时推导，低于成本价标红）
    ├── VersionChains.vue     # 版本链时间线（含已失效/已撤回旧价）
    └── FuelPrices.vue        # 油品挂牌价 / 成本价维护
```
